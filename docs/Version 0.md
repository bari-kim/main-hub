## 1. 시간대 시스템

사용자의 현재 시간을 기준으로 방의 시간대를 변경한다.

### 시간대 구분

처음에는 지나치게 세분화하지 않고 네 단계 정도가 적당해.

| 시간대 | 기준 예시 | 표현 |
| --- | --- | --- |
| 아침 | 06:00–10:59 | 옅은 노란 자연광 |
| 낮 | 11:00–16:59 | 밝고 중립적인 자연광 |
| 저녁 | 17:00–19:59 | 주황빛 노을 |
| 밤 | 20:00–05:59 | 어두운 필터와 실내조명 |

시간 경계에서 갑자기 화면이 바뀌지 않도록 필터와 빛의 투명도를 천천히 전환한다.

---

## 2. 창밖 시간대 변화

창문은 여러 레이어로 분리한다.

```
Window Frame
Sky
Seasonal Foreground
Weather
```

### Sky

- 아침 하늘
- 낮 하늘
- 노을 하늘
- 밤하늘

하늘을 이미지로 네 장 제작해도 되고, 단순한 풍경이라면 기본 하늘 한 장에 색상 필터를 적용해도 된다.

창틀은 항상 같은 이미지를 사용한다.

---

## 3. 자연광

창문에서 실내로 들어오는 빛을 별도의 투명 마스크로 제작한다.

```
natural-light-mask.png
```

빛의 모양은 한 장만 만들고 웹에서 다음 값을 변경한다.

- 색상
- 투명도
- 밝기
- 표시 여부

### 시간대별 자연광

- 아침: 연한 크림색, 비교적 긴 빛
- 낮: 밝은 흰색, 낮은 투명도
- 저녁: 주황색, 조금 더 선명한 빛
- 밤: 자연광 OFF 또는 아주 약한 푸른 달빛

빛의 각도까지 크게 바꾸려면 여러 장이 필요하므로, v0.4에서는 **같은 형태의 빛을 색상과 투명도로만 변화**시키는 편이 좋아.

---

## 4. 방 전체 분위기 필터

벽, 바닥, 가구를 시간대별로 다시 그리지 않고 방 전체에 색상 레이어를 올린다.

### 예시

- 아침: 약한 노란색
- 낮: 거의 투명
- 저녁: 약한 주황색
- 밤: 남색 또는 보라색

이 레이어는 아주 옅게 사용하고, 시간대의 주된 표현은 창밖과 자연광이 담당하게 한다.

---

## 5. 조명 ON/OFF

밤에는 실내조명이 자동으로 켜진다.

필요한 리소스:

```
lamp-off.png
lamp-on.png
lamp-glow.png
```

다만 전등 자체가 작다면 전구 부분만 켜진 버전 한 장을 추가하고, 빛의 범위는 `lamp-glow.png`로 분리하면 된다.

### 인터랙션

플레이어가 전등을 직접 클릭해 켜고 끌 수도 있다.

- 낮: 기본적으로 OFF
- 밤: 기본적으로 ON
- 사용자 조작 시 현재 방문 동안 설정 유지

밤에 불을 끄면 창밖과 달빛만 남는 분위기도 만들 수 있다.

---

# 6. 계절 시스템

계절은 실내 전체가 아니라 **창밖 풍경을 중심으로 표현**한다.

| 계절 | 창밖 표현 |
| --- | --- |
| 봄 | 벚꽃 나무 |
| 여름 | 짙은 초록 나무 |
| 가을 | 주황색·갈색 잎 |
| 겨울 | 앙상한 나무 또는 눈 쌓인 풍경 |

창문 구조를 다음처럼 분리하면 하늘과 계절을 자유롭게 조합할 수 있다.

```
Sky: 시간대 담당
Seasonal Foreground: 계절 담당
Weather Particles: 날씨 담당
```

따라서 `winter-night`, `winter-day`, `spring-night`를 각각 따로 그릴 필요가 없다.

```
Night Sky + Winter Foreground
Day Sky + Winter Foreground
Night Sky + Spring Foreground
```

형태로 조합하면 된다.

# 날짜 이벤트 시스템의 기반

v0.4에서 시간과 계절을 판정하는 시스템을 만들면, 이후에는 같은 구조로 **특정 날짜 이벤트**를 쉽게 추가할 수 있어.

우선순위는 이렇게 잡으면 돼.

```
기본 계절
↓
기간 이벤트
↓
특정 날짜 이벤트
```

상위 이벤트가 기본 환경 위에 장식 레이어를 추가하는 구조야.

---

## 크리스마스 이벤트

예를 들어 12월에는 다음 장식을 표시한다.

- 창문에 작은 리스
- 전구 가랜드
- 신발장 위 미니 트리
- 눈 파티클
- CD 플레이어의 크리스마스 음악

전부 넣기보다는 매년 한두 개씩 추가해도 좋아.

```
기본 겨울방
+ Christmas Decoration Layer
```

이렇게 별도 레이어로 관리하면 12월이 끝난 뒤 숨기기만 하면 된다.

---

## 생일 이벤트

생일에는 신발장이나 책상 위 기존 빈 공간에 케이크를 표시한다.

```
birthday-cake.png
```

가능한 연출:

- 케이크 등장
- 작은 촛불 애니메이션
- 방명록 옆에 생일 카드
- 접속 시 짧은 축하 메시지
- 생일 전용 음악

생일이 끝나면 자동으로 사라진다.

케이크를 상시 오브젝트로 두는 게 아니라 **해당 날짜에만 표시되는 이벤트 스프라이트**로 처리하면 된다.

---

## 그 밖의 날짜 이벤트

이 구조를 이용하면 나중에 소규모 이벤트를 계속 추가할 수 있어.

- 새해: 창밖 불꽃놀이
- 만우절: 가구 하나가 이상한 모습으로 변경
- 할로윈: 신발장 위 호박
- 사이트 개장일: 작은 기념 장식
- 첫눈이 온 날: 눈사람 장식
- 특정 업데이트 기념일: 오래된 포스트잇 재등장

이벤트마다 방 전체를 바꾸기보다 **작은 오브젝트 1개와 효과 1개** 정도로 제한하는 게 Bari's Room 방향에 잘 맞아.
