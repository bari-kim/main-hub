# Bari's Room Architecture

> Version: 1.0\
> Last Updated: 2026-07-28

------------------------------------------------------------------------

# 1. 목적

Bari's Room은 단순한 웹사이트가 아니라 사용자가 직접 걸어 다니며 공간을
탐험하는 **Living Workshop** 프로젝트이다.

모든 구조는 유지보수성과 확장성을 최우선으로 설계한다.

------------------------------------------------------------------------

# 2. 프로젝트 구조

``` text
app/
assets/
docs/
game/
public/
```

## app

-   Next.js(App Router)
-   페이지, 레이아웃, 전역 스타일

## assets

게임 리소스만 저장한다.

``` text
characters/
objects/
tiles/
backgrounds/
effects/
audio/
```

**이미지만 저장하며 코드는 넣지 않는다.**

## game

게임 코드만 저장한다.

``` text
camera/
constants/
entities/
input/
scenes/
systems/
ui/
utils/
world/
Game.ts
```

------------------------------------------------------------------------

# 3. Entities

게임 안에서 존재하는 객체를 관리한다.

``` text

└── npc/
```

# 14. 설계 원칙

-   하나의 클래스는 하나의 책임만 가진다.
-   렌더링과 게임 로직을 분리한다.
-   렌더링 크기와 충돌 영역을 분리한다.
-   UI는 게임 로직을 직접 수정하지 않는다.
-   Player는 Camera를 모른다.
-   Camera는 World를 본다.
-   Scene은 필요한 시스템을 조립한다.

------------------------------------------------------------------------

# 15. 변경 원칙

-   폴더 구조는 특별한 이유가 없는 한 변경하지 않는다.
-   새로운 기능은 기존 구조를 확장하는 방식으로 추가한다.
-   구조를 변경할 경우 먼저 **Architecture.md**를 수정한 뒤 코드에
    반영한다.
